## Own products, 2026

- **[Comandea](https://comandea.es):** an offline-first POS for restaurants and bars, in pilot with its first venue. Waiter tablets sync through a local hub. It implements Spain's Veri*Factu invoicing (SHA-256 hash chain, AEAT QR) with Canary Islands IGIC and is covered by 1,585 automated tests. React Native / Expo, TypeScript, SQLite, Node, Supabase.
- **Eva:** an AI WhatsApp assistant for Hotel Coroana (43 rooms), where reception, housekeeping and maintenance manage rooms and issues with role-based permissions. Next.js, Claude API (tool use, prompt caching), Supabase, Twilio.
- **Google Reviews Bot:** replies to Google reviews for 5 business locations in the reviewer's language. 4–5★ replies post automatically, 1–3★ replies wait for approval by email. Google approved our Business Profile API access. Next.js, Claude API, Supabase, Resend.
